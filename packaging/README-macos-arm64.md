# SvinDB для macOS arm64

Готовая сборка для компьютеров Apple Silicon.

## Запуск

Откройте Terminal в распакованном каталоге и выполните:

```bash
./svindb serve 19300
```

Узел слушает `127.0.0.1:19300`. Каталог `data` рядом с бинарником используется
для документов, WAL и сегментов. При первом обычном запуске он создаётся
автоматически.

Ограниченные режимы:

```bash
./svindb serve 19300 --read-only
./svindb serve 19300 --no-maintain
```

Явный каталог данных:

```bash
./svindb serve /путь/к/данным 19300
```

Если macOS блокирует загруженный бинарник, откройте его один раз через
Finder → «Открыть» и подтвердите запуск.

## Проверка файла

```bash
shasum -a 256 -c SHA256SUMS
```
